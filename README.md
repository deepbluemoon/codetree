# Algorithm Practice Archive

Python과 C로 기초 문법부터 반복문, 배열, 함수까지 단계적으로 풀이한 코딩 테스트 학습 기록입니다.

## 학습 목표

- 문제를 작은 입력·처리·출력 단계로 나누는 습관 형성
- 조건문, 반복문, 배열, 문자열, 함수의 반복 학습
- 같은 문제를 Python과 C로 다시 풀며 언어별 구현 차이 비교
- 풀이 일자를 기준으로 학습 흐름과 꾸준함 기록

## 저장소 구성

각 날짜 폴더 아래에 문제별 폴더가 있으며, 문제 설명 `README.md`와 풀이 코드가 함께 저장되어 있습니다.

```text
YYMMDD/
├── README.md
├── 문제명/
│   ├── README.md
│   └── solution.py
└── 문제명/
    ├── README.md
    └── solution.c
```

## 사용 언어

- Python
- C

## 학습 내용

- 입출력과 기본 자료형
- 조건문과 논리 연산
- 반복문과 흐름 제어
- 1차원·2차원 배열
- 문자열 처리
- 함수 기반 문제 해결

## 포트폴리오 관점

이 저장소는 완성형 서비스가 아니라 알고리즘 기초와 문제 해결 과정을 보여주는 학습 아카이브입니다. 프로젝트 저장소와 분리해 꾸준한 학습 기록을 증명하는 용도로 관리합니다.

## 향후 개선

- 대표 문제에 시간·공간 복잡도 설명 추가
- 유형별 인덱스와 풀이 회고 작성
- 중복 풀이 정리 및 테스트 케이스 보강
